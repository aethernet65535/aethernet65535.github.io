[N] - Optimize: remove unnecessary calculate

在我的 DAMON 使用场景（主动内存回收）中，由于 MemAvailable 大多数时候都是相当充足的，所以基本没有需要 Apply 的情况。但是，DAMON 在一个 Scheme Apply 前，大概率会先去计算一些东西，即使该 Scheme 完全不可能 Apply 任何 Region（因为没有任何必要）。

所以，我会在讨论证明我的优化可以减少不必要的开销后，去和 SJ 讨论是否有必要在现阶段让我来开发这个补丁。

---

[N] - Bug: effective size quota stuck

目前的代码中，如果本来有设置 Quota，之后很准时地 Unset 了 Quota，那么，Effective Size Quota 会被卡住，进而导致之后不能再调整 Effective Size Quota，也会保留 Quota 的限制，换句话来说就是 Quota 还存在。

我想这大概率是预期之外的行为。不过...先讨论吧，我真怕了。(。﹏。*)
